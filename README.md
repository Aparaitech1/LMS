
# 📚 LMS Website

A full-stack **Learning Management System (LMS)** built using the **MERN stack** — MongoDB, Express.js, React.js, and Node.js.  
This project allows users to browse, enroll, and manage courses with a modern, responsive UI.

---

## 🌐 Live Demo
🔗 [LMS Website](https://lms-full-stack-blond.vercel.app/)

---

## ⚙️ Tech Stack
- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)  
- **Authentication:** Clerk

---

## 🚀 Features
✅ User registration & login  
✅ Course catalog with search and filters  
✅ Instructor and student dashboards  
✅ Secure JWT authentication  
✅ Responsive UI for all devices
